# Análisis de Eficiencia Algorítmica con Big O y Estructuras de Datos

## 📝 Descripción del Problema
Una universidad administra una amplia base de datos de estudiantes. Cada registro contiene carnet, nombre, carrera, departamento y promedio. Dado que el sistema realiza consultas de existencia e identificación de forma masiva, este proyecto evalúa el impacto del rendimiento y escalabilidad de diferentes estructuras de datos (Listas, Conjuntos, Diccionarios, Listas Enlazadas y Árboles Binarios de Búsqueda) al procesar grandes volúmenes de datos reales descargados desde GitHub.
